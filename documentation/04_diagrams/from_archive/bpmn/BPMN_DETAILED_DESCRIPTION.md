## 🔄 Описание бизнес-процессов

### 📋 Текущий процесс (AS IS)

#### Основные этапы:
1. **Инициация заявки**
   - Сотрудник создает заявку (email/телефон)
   - Ручная передача руководителю

2. **Обработка руководителем**
   - Ручная проверка данных
   - Ручное согласование/отклонение
   - Ручное формирование таблицы

3. **Координация**
   - Координатор собирает заявки
   - Формирование CSV файла
   - Отправка перевозчику

#### Проблемы текущего процесса:
- Отсутствие единой базы заявок
- Дублирование информации
- Сложность отслеживания статуса
- Высокие временные затраты
- Человеческий фактор

### 🎯 Целевой процесс (TO BE)

#### Оптимизированные этапы:
1. **Автоматизированная подача**
   - Создание заявки через веб или Telegram-бот
   - Автоматическая валидация данных
   - Сохранение в единую базу

2. **Централизованная обработка**
   - Веб-интерфейс для руководителей
   - Массовая обработка заявок
   - Автоматические уведомления

3. **Автоматический экспорт**
   - Формирование CSV одним кликом
   - Интеграция с перевозчиком
   - Аудит всех действий
