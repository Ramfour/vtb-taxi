# Диаграммы проекта

## 📋 Содержание папки

В этой папке находятся все диаграммы проекта в формате Draw.io:

### 🎨 Архитектурные диаграммы:
- **`$architecture.drawio.bkp`** - Общая архитектура системы
- **`$architecture_backend.drawio.bkp`** - Архитектура бэкенда
- **`$architecture_frameworks.drawio.bkp`** - Архитектура фреймворков
- **`$architecture_frontend.drawio.bkp`** - Архитектура фронтенда
- **`$architecture_server.drawio.bkp`** - Архитектура сервера

### 🗄️ Диаграммы базы данных:
- **`$db_schema.drawio.bkp`** - Схема базы данных

### 👥 Use Case диаграммы:
- **`$usecase_admin.drawio.bkp`** - Use Case для администратора
- **`$usecase_employee.drawio.bkp`** - Use Case для сотрудника
- **`$usecase_manager.drawio.bkp`** - Use Case для менеджера

## 📊 Типы диаграмм:

### **Архитектурные диаграммы** показывают:
- Структуру компонентов системы
- Взаимодействие между модулями
- Потоки данных и управления
- Разделение на слои (presentation, business, data)

### **Диаграмма базы данных** включает:
- Все таблицы системы
- Связи между таблицами
- Типы данных и индексы
- Ограничения целостности

### **Use Case диаграммы** описывают:
- Функциональность для каждой роли
- Основные сценарии использования
- Взаимодействие пользователя с системой
- Границы ответственности

## 🔧 Использование:
Все диаграммы созданы в **Draw.io** и могут быть отредактированы:
1. Откройте файлы в [Draw.io](https://app.diagrams.net/)
2. Внесите необходимые изменения
3. Экспортируйте в нужном формате (PNG, SVG, PDF)

---
*Диаграммы поддерживаются в актуальном состоянии и отражают текущую архитектуру*
