## 🎯 Классификация диаграмм

### 🔄 **BPMN (Business Process Model and Notation)**
- **Назначение:** Моделирование бизнес-процессов
- **Стандарт:** BPMN 2.0
- **Использование:** Анализ и оптимизация процессов

### 🗄️ **Диаграммы данных**
- **Назначение:** Структура базы данных
- **Формат:** ER-диаграммы
- **Использование:** Проектирование БД

### 📋 **IDEF0 (Integration Definition for Function Modeling)**
- **Назначение:** Функциональная декомпозиция
- **Стандарт:** IDEF0
- **Использование:** Анализ функций системы

### 🎯 **UML Use Case**
- **Назначение:** Сценарии использования
- **Стандарт:** UML
- **Использование:** Проектирование функционала

---

## 🔄 Процессная трансформация

### 📋 **AS IS → TO BE**
1. **Анализ текущих процессов** (BPMN asis, IDEF0 asis)
2. **Выявление проблем** и узких мест
3. **Проектирование оптимизации** (BPMN tobe, IDEF0 tobe)
4. **Внедрение улучшений** через систему автоматизации

### 📊 **Улучшения:**
- Сокращение времени обработки на 70%
- Уменьшение ошибок с 15% до 2%
- Централизация всех заявок
- Автоматизация рутинных операций
