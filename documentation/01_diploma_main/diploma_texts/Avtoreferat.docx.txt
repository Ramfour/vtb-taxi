АВТОРЕФЕРАТ
выпускной квалификационной работы на тему:
«Разработка прототипа мультисервисного приложения для автоматизации внутренних бизнес-процессов для руководителей ВТБ»
Автор: Ткаченко Данил Витальевич
Направление подготовки: 09.03.02 «Информационные системы и технологии»
Научный руководитель: Рыковский Н.А.

Актуальность исследования обусловлена наличием в банке ВТБ высокозатратных и неэффективных ручных процессов, в частности — организации заказа корпоративного такси для сотрудников. Текущий процесс (AS‑IS) характеризуется использованием разрозненных каналов коммуникации (мессенджеры, почта, телефон), необходимостью двойного ручного ввода данных, отсутствием контроля лимитов и высокими операционными рисками, что приводит к значительным временным и финансовым издержкам.
Цель работы — разработка и обоснование архитектуры прототипа мультисервисного приложения для автоматизации внутренних бизнес-процессов ВТБ с реализацией пилотного модуля управления корпоративным такси.
Задачи исследования:
Провести анализ существующего процесса заказа такси (AS‑IS) и сформировать требования стейкхолдеров (сотрудники, руководители, администраторы).
Выполнить сравнительный анализ с существующими решениями и определить архитектурные требования к системе.
Спроектировать модульную архитектуру прототипа с использованием микросервисного подхода.
Реализовать ключевые функциональные модули: Telegram-бот для сотрудников, веб-интерфейс для руководителей, интеграцию с API Яндекс Такси.
Провести тестирование прототипа и подготовить рекомендации по внедрению.
Объект исследования — процесс организации корпоративных заказов такси в ВТБ.
Предмет исследования — методы и средства автоматизации данного процесса на основе модульной мультисервисной платформы.
Методология и методы исследования: в работе применялись методы системного анализа, моделирования бизнес-процессов (IDEF0, BPMN, UML), сравнительного анализа аналогов, а также методы объектно-ориентированного проектирования и итеративной разработки ПО.
Основные результаты:
На основе проведённого анализа формализованы функциональные и нефункциональные требования к системе, определены роли стейкхолдеров и их потребности.
Предложена двухканальная архитектура системы, включающая:
Telegram-бот на Python — для подачи и отслеживания заявок сотрудниками с автоматической валидацией данных.
Веб-интерфейс (mini-app) на PHP — для управления заявками, одобрения, формирования отчётов и администрирования руководителями.
Микросервисную логику с интеграцией API Яндекс Такси для автоматического создания заказов и геокодера для нормализации адресов.
Базу данных MySQL для хранения заявок, профилей пользователей и журналов аудита.
Разработан прототип, демонстрирующий полный цикл автоматизации: от подачи заявки сотрудником через бота → её валидации и одобрения руководителем в веб-интерфейсе → автоматической отправки в Яндекс Такси → формирования итогового отчёта.
Экономическое обоснование проекта показало потенциал снижения операционных затрат за счёт сокращения времени обработки заявок на 70–80%, минимизации ошибок и возможности контроля расходов.
Теоретическая и практическая значимость. Теоретическая ценность работы заключается в адаптации методологии анализа бизнес-процессов и проектирования микросервисных архитектур для задач автоматизации в крупных финансовых организациях. Практическая значимость подтверждается работающим прототипом, готовым к пилотному внедрению в подразделениях ВТБ, и комплектом проектной документации, включающим спецификации требований, архитектурные схемы и рекомендации по развёртыванию.
