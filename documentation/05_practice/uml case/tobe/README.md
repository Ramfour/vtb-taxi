# UML Use Case (TO-BE): Описание Диаграмм

Эта папка содержит Use Case диаграммы (вариант TO-BE) для текущего проекта “Корпоративное такси”.

Диаграммы описывают сценарии и права трёх ролей:

- **Employee (Сотрудник)**
- **Manager (Руководитель)**
- **Admin (Администратор)**

Файлы диаграмм:

- `usecase_employee.drawio`
- `usecase_manager.drawio`
- `usecase_admin.drawio`

Ниже приведено текстовое описание каждой диаграммы. Для удобства отдельные подробные описания также вынесены в файлы:

- `usecase_employee.md`
- `usecase_manager.md`
- `usecase_admin.md`
