1 Описание предметной области, актуальность решаемой задачи 
ПАО «ВТБ» – один из крупнейших банков России, осуществляющий полный спектр финансовых услуг для физических и юридических лиц. Объек-том автоматизации является отдел дистанционного клиентского обслужива-ния (ДКО) новосибирского офиса ПАО «ВТБ». Сотрудники отдела регулярно используют корпоративное такси для служебных поездок.
В текущем состоянии процесс организации поездок выполняется вруч-ную: заявки поступают через мессенджеры, электронную почту и устные об-ращения, руководитель вынужден самостоятельно консолидировать их в таб-лицу и формировать файл для перевозчика. Это создаёт накопительный эф-фект повторяющихся операций, риск потери заявок и ошибок при переносе данных.
Актуальность задачи определяется необходимостью автоматизации внутреннего цикла сбора, согласования и выгрузки заявок – участка процесса, который не покрывается ни внешними сервисами такси, ни универсальными CRM-системами в разумном объёме затрат.
Текущее состояние процесса отражено на диаграмме вариантов исполь-зования AS-IS (рисунок 1), на которой показаны основные участники и их взаимодействие до внедрения системы.

Функциональные требования:
•	регистрация и авторизация с разграничением ролей (Employee, Manager, Admin);
•	создание, просмотр и отмена заявки сотрудником;

•	формирование CSV-выгрузки для перевозчика;
•	аудит действий пользователей; управление пользователями (Admin).
Нефункциональные требования:
•	веб-интерфейс через браузер, работа по HTTPS;
•	CSRF-защита, хранение паролей bcrypt;
•	время отклика не более 2 секунд для типовых операций.

private function buildCsvContent($requests): string
{    $handle = fopen('php://temp', 'r+');
    fwrite($handle, "\xEF\xBB\xBF");
    fputcsv($handle, ['Номер', 'Дата и время', 'ФИО', 'Адрес подачи', 'Телефон'], ';');
    $index = 1;
    foreach ($requests as $requestRow) {
        fputcsv($handle, [
            $index,
            $requestRow['date_time'],
            $requestRow['full_name'],
            $requestRow['address'],
            $requestRow['phone'],
        ], ';');
        $index++;
    }
    rewind($handle);
    $content = stream_get_contents($handle);
    fclose($handle);

    return $content;

7 Проблемы, пути их решения, рекомендации
В ходе разработки и тестирования были выявлены следующие проблемы и найдены решения:
•	Проблема при развёртывании на хостинге некорректно работали сессии и логи.
•	Решение настройка прав на каталог storage, корректный .env для produc-tion.
•	Проблема при параллельной подаче заявок возможно дублирование на одно время.
•	Решение серверная проверка на дублирование по user_id + ride_at перед сохранением.
•	Проблема таблицы с большим числом заявок медленно отрабатывали фильтрацию.
•	Решение добавление индексов на поля status, user_id, ride_at в миграци-ях.
