# 📚 Документация проекта "Корпоративное такси"

## 🎯 Обзор проекта

Система автоматизации заказа корпоративного такси для сотрудников отдела дистанционного клиентского обслуживания ПАО «ВТБ» в г. Новосибирске.

### 🏗️ Архитектура
- **Модульный монолит** на базе Laravel
- **Двухслойная обработка** заявок (temp_requests → requests)
- **Ролевая модель**: Employee, Manager, Admin
- **Многоклиентность**: веб-портал + Telegram-бот

## 🔑 Ключевые особенности

### **Безопасность**
- Аутентификация через Laravel сессии
- Ролевое разделение доступа (Employee/Manager/Admin)
- CSRF защита всех форм
- Аудит всех значимых действий
- Хеширование паролей bcrypt
- HTTPS для административных функций

### **Бизнес-логика**
- Двухэтапная обработка заявок
- Буферный и финальный слои данных
- Массовая обработка заявок
- CSV выгрузка для перевозчика
- История всех изменений

### **Технологии**
- **Backend**: Laravel 13.x
- **Frontend**: Blade + Tailwind CSS
- **Database**: MySQL 8.4
- **Bot**: Telegram Bot API
- **Deployment**: Docker + Nginx
