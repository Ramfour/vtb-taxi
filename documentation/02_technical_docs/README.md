# Техническая документация проекта

## 📋 Содержание папки

В этой папке находится техническая документация по проекту "Корпоративное такси":

### 📚 Документы:
- **`00_glossary.md`** - Глоссарий проекта и основные термины
- **`01_architecture.md`** - Архитектура системы и компоненты
- **`02_database.md`** - Описание базы данных и схема
- **`03_tech_stack.md`** - Технологический стек и инструменты
- **`04_troubles_and_lessons.md`** - Проблемы и извлеченные уроки
- **`05_security.md`** - Безопасность и защита данных
- **`06_ui_interfaces.md`** - Описание пользовательских интерфейсов
- **`07_bot_api_integration.md`** - Интеграция с Telegram ботом и API
- **`правки_для_docx.md`** - Правила оформления для Word документов

## 🏗️ Архитектурные особенности:
- **Модульный монолит** на базе Laravel
- **Двухслойная обработка заявок**: temp_requests → requests
- **Ролевая модель**: Employee, Manager, Admin
- **Два клиента**: веб-портал и Telegram-бот

## 🔒 Безопасность:
- Аутентификация через сессии Laravel
- CSRF защита форм
- Ролевое разделение доступа
- Аудит действий пользователей
- Хеширование паролей bcrypt
- HTTPS для административных функций

## 📊 База данных:
- **MySQL** как основная СУБД
- Основные таблицы: users, temp_requests, requests, audit_log
- Связи и индексы оптимизированы под бизнес-процессы
