# Глоссарий

Этот файл — единый словарь терминов проекта (продукт + технические термины), чтобы схемы draw.io и документация читались без контекста.

## Продуктовые термины

- **Заявка**: запись о планируемой поездке (ФИО, телефон, адрес подачи, дата/время).
- **Буфер заявок**: слой “на согласовании” в таблице `temp_requests`.
- **Финальный слой / база перед выгрузкой**: слой подтвержденных заявок в таблице `requests`, который является источником CSV.
- **Согласование**: действие руководителя (Manager/Admin), которое переводит заявку из `Pending` в `Approved`/`Rejected`.
- **Перенос в финальный слой (Finalize)**: операция, которая создает `requests` на основе одобренных `temp_requests`.
- **Выгрузка CSV**: формирование и скачивание итогового файла для перевозчика.
- **Аудит**: журнал действий пользователей (таблица `audit_logs`).
- **Приглашение**: токен для регистрации пользователя (таблица `invitations`).
- **Табельный номер**: `employee_number`, используется как логин/идентификатор сотрудника.

## Роли (UserRole)

Enum: `App\Enums\UserRole`

- **Employee (1)**: сотрудник, подает заявки и видит свои заявки.
- **Manager (2)**: руководитель, согласует заявки, управляет приглашениями (в пределах прав).
- **Admin (3)**: администратор, расширенные права (управление пользователями, аудит и т.п.).

## Статусы заявок (RequestStatus)

Enum: `App\Enums\RequestStatus`

- **Pending (1)**: на согласовании.
- **Approved (2)**: одобрено.
- **Rejected (3)**: отклонено.
- **Cancelled (4)**: отменено (обычно сотрудником или системой).
- **Expired (5)**: просрочено (время поездки уже прошло, заявка автоматически переводится в `Expired`).

## Статусы уведомлений (NotificationStatus)

Enum: `App\Enums\NotificationStatus`

- **Pending (0)**: ожидает отправки.
- **Sent (1)**: отправлено.
- **Failed (2)**: ошибка отправки.

## Термины БД и данных

- **MySQL**: реляционная база данных проекта.
- **Таблица**: набор строк одинаковой структуры (например `users`, `requests`).
- **PK (Primary Key)**: первичный ключ — уникальный ID строки (`id`).
- **FK (Foreign Key)**: внешний ключ — ссылка на другую таблицу (например `requests.user_id -> users.id`).
- **Index (индекс)**: ускоряет выборки (например по `status`, `date_time`).
- **Unique constraint**: запрет дубликатов; у нас есть `unique(user_id, date_time)` для заявок.
- **Migration (миграция)**: код, который создает/меняет структуру таблиц (`database/migrations/...`).
- **Schema drift**: расхождение схемы БД и кода (частая причина `Unknown column ...`).
- **Soft delete**: “мягкое удаление” через поле `deleted_at` (строка скрывается, но физически остается).
- **Force delete**: окончательное удаление строки из БД.
- **Retention policy**: политика хранения данных (через сколько дней чистить буфер/аудит/финальные заявки).
- **exported_at**: время, когда финальная заявка попала в CSV; используется для авто-очистки через N дней.

## Backend (Laravel) термины

- **Laravel**: PHP-фреймворк, на котором построено приложение.
- **Artisan**: консольный инструмент Laravel (`php artisan ...`).
- **Route (маршрут)**: правило, которое связывает URL+HTTP-метод с контроллером.
- **Controller (контроллер)**: обработчик запроса (принимает input, вызывает бизнес-логику, возвращает response).
- **Middleware (промежуточный слой)**: фильтр/прослойка “до/после” контроллера (роль, auth, CSRF, и т.п.).
- **Service layer (сервисный слой)**: классы бизнес-логики (например `RequestWorkflowService`).
- **Eloquent**: ORM Laravel (модели + запросы к БД).
- **Blade**: шаблонизатор Laravel для серверного рендера HTML.
- **CSRF**: защита POST/PUT/DELETE запросов (токен в форме). Ошибка 419 часто связана с CSRF/сессиями.
- **Session**: серверная/файловая сессия пользователя (вход, CSRF и т.п.).
- **APP_KEY**: ключ приложения Laravel; нужен для шифрования cookies/сессий и корректной работы логина.

## Frontend термины

- **Vite**: сборщик фронтенда (dev server + production build).
- **Tailwind CSS**: CSS-фреймворк (утилитарные классы).
- **manifest.json (Vite)**: файл, который связывает исходные ассеты и собранные файлы в `public/build/`.

## Сервер/инфраструктура

- **DNS**: связывает домен (`vtb-taxi.ru`) с IP сервера.
- **A/AAAA**: DNS записи для IPv4/IPv6. Если они ведут на разные сервера — возможны “странные” проблемы с SSL.
- **CNAME**: DNS-алиас (часто для `www`).
- **HTTPS**: защищенный HTTP поверх TLS.
- **SSL/TLS сертификат**: подтверждает домен и шифрует соединение.
- **Let’s Encrypt**: бесплатный центр сертификации, выдает сертификаты обычно на ~90 дней.
- **nginx/Apache**: веб-сервер.
- **FastCGI**: протокол связи web-сервера и PHP runtime.
- **PHP-FPM/CGI**: способы запуска PHP в web-режиме.
- **Cron**: планировщик на сервере/хостинге.
- **Laravel Scheduler**: планировщик Laravel, который требует cron для запуска `schedule:run`.
- **schedule:run**: команда, которую обычно запускают раз в минуту, чтобы Laravel выполнял запланированные задачи.
- **taxi:cleanup**: команда проекта для очистки данных по retention.
