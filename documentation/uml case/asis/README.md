# UML / AS-IS: Описание Диаграмм

Эта папка содержит **AS-IS** диаграммы (ранняя/историческая версия требований и процесса).

По ходу разработки проект эволюционировал в два равноправных интерфейса: веб-портал (Laravel + MySQL + роли + CSV экспорт) и Telegram-бот (Python/aiogram), работающий через Laravel API. Часть AS-IS диаграмм может содержать упоминания:

- "бота" / "сообщений" — это раннее представление о боте как единственном интерфейсе (до появления веб-портала),
- "нормализации адресов" как отдельного обязательного шага,
- "уведомлений" и т.п.

Это нормально: AS-IS диаграммы сохранены как материал для диплома (как было задумано/описано на старте). Актуальная архитектура описана в `01_architecture.md`.

Файлы диаграмм:

- `uml.xml` / `uml.drawio` — объединенная Use Case диаграмма для сотрудника и руководителя (AS-IS).
- `сотрудник.xml` — Use Case диаграмма для сотрудника (AS-IS).
- `руководитель.xml` — Use Case диаграмма для руководителя (AS-IS).
- `bpmn1.drawio.png` — экспорт BPMN/процесса (AS-IS) в PNG.
