
Слайд 2. Актуальность
«Сейчас процесс заказа такси в отделе ДКО полностью ручной. Основной проблемой является не чрезмерная длительность обработки одной  заявки, а совокупный эффект множества мелких действий, повторяющихся в  течение рабочего дня: чтение сообщений, перенос данных в таблицу, уточнение адресов, повторное открытие переписки, корректировка строк и формирование итогового файла.».

Слайд 3. Цель и задачи
«Цель — разработать прототип приложения для автоматизации внутреннего процесса заказа корпоративного такси: централизованный сбор, согласование, хранение и выгрузку заявок в CSV, с основой для расширения на другие внутренние сервисы организации».

Слайд 4. Сравнение с аналогами
«Excel и табличные процессоры не обеспечивают целостность данных и контроль статусов. CRM-системы избыточны для узкоспециализированного процесса. Системы электронного документооборота плохо подходят для оперативного сценария с частыми корректировками. Внешние сервисы такси не автоматизируют внутренний цикл согласования.».

Слайд 5. Стейкхолдеры
«Ключевые заинтересованные стороны: руководитель — нуждается в автоматизации рутины и прозрачности; сотрудник — в простом канале подачи; администратор — в стабильности и аудите; департамент колл-центра — заинтересованность связана с повышением операционной эффективности. Глоссарий терминов презентации
Модульный монолит
Архитектурный подход, при котором приложение разбито на изолированные модули с чёткими границами, но развёртывается и работает как единый процесс. «Монолит» — единица развёртывания (один сервер, один запуск). «Модульный» — внутренняя организация кода. В отличие от микросервисов, не требует сложной распределённой инфраструктуры, что делает решение проще в сопровождении.
Laravel
Популярный PHP-фреймворк для быстрой и безопасной разработки веб-приложений. Предоставляет готовые инструменты для маршрутизации, авторизации, работы с базой данных через Eloquent ORM, шаблонизатор Blade и планировщик задач.
Aiogram 3
Асинхронный Python-фреймворк для создания Telegram-ботов. Позволяет обрабатывать множество сообщений одновременно без задержек.
Blade
Встроенный шаблонизатор Laravel. Позволяет генерировать HTML-страницы на сервере, смешивая разметку с PHP-логикой. Используется для построения всех экранов системы.
Tailwind CSS
Utility-first CSS-фреймворк для стилизации интерфейса. Вместо написания отдельных CSS-файлов разработчик применяет готовые классы прямо в разметке, что ускоряет вёрстку и обеспечивает единый визуальный стиль.
Vite
Инструмент сборки фронтенд-ресурсов (CSS, JavaScript). Обеспечивает быструю компиляцию и горячую перезагрузку во время разработки. В проекте используется совместно с Laravel.
Eloquent ORM
Встроенный в Laravel инструмент для работы с базой данных через объекты PHP, без написания SQL-запросов вручную. Каждая таблица (пользователи, заявки, аудит) представлена отдельной моделью.
MySQL
Реляционная система управления базами данных. Хранит все данные системы: пользователей, заявки на согласовании, финальные заявки, журнал аудита и историю адресов. Обеспечивает целостность данных через связи между таблицами и ограничения уникальности.
Docker Compose
Инструмент для запуска многоконтейнерных приложений. В проекте используется для локальной разработки: поднимает nginx, php-fpm и MySQL в изолированных контейнерах с воспроизводимой конфигурацией.
RBAC (Role-Based Access Control)
Ролевая модель управления доступом. Каждому пользователю назначается роль (сотрудник, руководитель или администратор), и система автоматически ограничивает доступные действия в соответствии с этой ролью.
CSV
Текстовый формат таблиц, совместимый с MS Excel. В системе используется для формирования итогового файла с подтверждёнными заявками, который руководитель передаёт перевозчику.
Дашборд (Dashboard)
Информационная панель, которая в одном окне собирает ключевые показатели и инструменты управления. В нашем случае — главный экран руководителя со сводкой по статусам и таблицей заявок.
AJAX
Технология обмена данными между браузером и сервером в фоновом режиме. Позволяет изменять статус заявки и видеть результат мгновенно, без перезагрузки всей страницы.
Журнал аудита
Хронологическая запись всех значимых действий пользователей в системе: кто, когда и что изменил. Необходим для расследования инцидентов, контроля дисциплины и соблюдения требований безопасности.
