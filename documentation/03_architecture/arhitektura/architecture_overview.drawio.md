# Легенда: architecture_overview.drawio

Файл: `_about/architecture_overview.drawio` — общая схема системы “в один экран”, без декомпозиции.

## Элементы схемы

- **Пользователь (Employee / Manager / Admin)**: конечный пользователь системы.
- **HTTPS + SSL (Let’s Encrypt)**: защищенное соединение браузера с сайтом.
- **Laravel App**: приложение (маршруты, контроллеры, сервисы, Blade UI).
- **MySQL**: база данных.
- **Storage (filesystem)**: файловое хранилище сервера (сессии/логи/экспорт).
- **Cron**: планировщик задач на хостинге, который запускает `schedule:run`.

## Термины

- **HTTPS**: HTTP поверх TLS. Дает шифрование и проверку подлинности сервера.
- **SSL/TLS**: протоколы шифрования. “SSL” в интерфейсах часто называют TLS по привычке.
- **Let’s Encrypt**: бесплатный удостоверяющий центр (CA), выпускает доверенные сертификаты на ~90 дней.
- **Laravel**: PHP-фреймворк, в котором реализована система.
- **Blade**: шаблонизатор Laravel (серверный рендер HTML).
- **MySQL**: реляционная база данных.
- **storage/**: директория Laravel для логов, кэшей, сессий, пользовательских файлов.
- **Cron**: системный планировщик (на shared-хостинге настраивается в панели).
- **artisan**: CLI-инструмент Laravel (команды `php artisan ...`).
- **schedule:run**: команда Laravel Scheduler, которая “тикает” и запускает запланированные задачи.

## Как читать стрелки

- `Пользователь → HTTPS → Laravel` — обычные запросы к сайту.
- `Laravel → MySQL/Storage` — чтение/запись данных.
- `Cron → Laravel` — фоновые регулярные задачи (очистка, обслуживание).
