## 🏗️ Архитектурная концепция

### 🎯 Основные принципы

1. **Модульный монолит** на Laravel
2. **Трехслойная архитектура:**
   - Клиентские приложения (веб + бот)
   - Серверная часть (Laravel ядро)
   - Данные и внешние системы (MySQL + Redis + API)

### 🔄 Двухэтапная обработка заявок

1. **Буферный слой** (`temp_requests`) - для согласования
2. **Финальный слой** (`requests`) - для экспорта

### 🛡️ Безопасность и масштабируемость

- HTTPS + SSL (Let's Encrypt)
- Ролевое разделение доступа (RBAC)
- Асинхронные операции через Redis Queue
- Слабая связанность компонентов

---

## 📊 Технологический стек

### 🎨 Frontend
- **Blade templates** - server-side UI
- **Tailwind CSS v4** - стили
- **Vite** - сборка ассетов
- **JavaScript (lightweight)** - интерактивность

### ⚙️ Backend
- **Laravel 13** - основной фреймворк
- **PHP 8.3** - runtime
- **Eloquent ORM** - работа с БД
- **Redis Queue** - асинхронные задачи

### 🗄️ Infrastructure
- **MySQL** - основная БД
- **nginx/Apache + FastCGI** - веб-сервер
- **Cron + Laravel Scheduler** - планировщик
- **Let's Encrypt** - SSL сертификаты

- **Централизованное управление** бизнес-логикой
