# План отчёта по практике

> Тема практики совпадает с темой ВКР.
> Объём записки: от 30 страниц с иллюстрациями.
> Отчёт — выжимка из диплома по 3 содержательным разделам (4-я глава БЖД в практику не входит).

---

## Структура отчёта

### Раздел 1 — Анализ предметной области
*(Консультант: по разделу 1)*

- Описание предприятия и его структуры (ПАО «ВТБ», отдел ДКО)
- Постановка задачи / техническое задание
- Анализ существующих решений (сравнение с аналогами)
- Обоснование необходимости разработки

**Источник в дипломе:** Глава 1

---

### Раздел 2 — Проектно-конструкторский
*(Консультант: по разделу 2)*

- Выбор архитектуры приложения (веб, клиент-сервер, монолит)
- Обзор и выбор технологий (фреймворки, СУБД, инструменты)
- Проектирование базы данных
- Схемы: архитектурная, ER-диаграмма, диаграмма компонентов

**Источник в дипломе:** Глава 2

---

### Раздел 3 — Технологический
*(Консультант: по разделу 3)*

- Карта сайта / структура интерфейса
- Описание основных режимов работы (Employee, Manager, Admin)
- Скриншоты ключевых экранов с комментариями
- Фрагменты кода (по минимуму, только ключевые места)
- Листинги (минимально)
- Результаты тестирования
- Краткий мануал пользователя

**Источник в дипломе:** Глава 3

---

## Что брать из диплома

| Из диплома                        | В практику                        |
|-----------------------------------|-----------------------------------|
| Гл. 1 — анализ, стейкхолдеры, аналоги | Раздел 1 целиком (сократить)  |
| Гл. 2 — архитектура, БД, схемы    | Раздел 2 (схемы обязательны)      |
| Гл. 3 — реализация, скриншоты     | Раздел 3 (скриншоты + мануал)     |
| Гл. 4 — БЖД                       | **Не включать**                   |
| Заключение диплома                | Краткое заключение практики       |
| Список источников                 | Сокращённый список                |
